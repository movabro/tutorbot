# T5 Weekly Report (v1)

주어진 SQL 집계 통계만을 바탕으로 주간 학습 요약 문장을 JSON으로 작성하세요. (숫자 지표는 코드가 헤더에 렌더링하므로 문장 위주로 핵심만 작성합니다.)

규칙:
- `summary`: 지난주 학습 흐름 요약 (3줄 이내 문자열)
- `weak_points`: 보완이 필요한 약점 영역 (최대 3개 배열)
- `next_week`: 다음 주 집중 추천 (최대 3개 배열)
- 반드시 아래 JSON 스키마만 출력하세요:
```json
{
  "summary": "≤3줄 요약",
  "weak_points": ["≤3개"],
  "next_week": ["≤3개"]
}
```
