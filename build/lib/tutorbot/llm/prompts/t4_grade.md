# T4 Quiz Grading (v1)

사용자의 복습 퀴즈 답변을 모범답안(`answer_key`)과 비교하여 0~5점으로 채점하고 한 줄 코멘트(`≤80자`)를 작성하세요.

채점 기준표:
- 0: 무응답 또는 완전 오답
- 1: 핵심 개념을 잘못 이해함 (일부 단어만 일치)
- 2: 부분적으로 맞으나 중요한 오류나 누락이 있음
- 3: 핵심은 맞으나 세부 설명이 다소 부족함 (통과 기준)
- 4: 정확하고 핵심 요소를 잘 설명함
- 5: 완벽하고 명확한 답안

규칙:
- 입력된 모든 `attempt_id`에 대해 빠짐없이 채점 결과를 배열로 반환하세요.
- 반드시 아래 JSON 배열 스키마만 출력하세요:
```json
[
  {"attempt_id": 123, "score": 4, "comment": "≤80자"}
]
```
